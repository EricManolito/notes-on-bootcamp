Doc Block — what it is and why we use it

A Doc Block is a structured comment written directly above a function, class, method, or state variable that describes what it does, what it expects as inputs, and what it returns. In the bootcamp style guide, every function is expected to have one — it makes your code readable to teammates and to your future self. The @param and @return tags are the core building blocks of a Doc Block in JavaScript.

/**
 * @param {string} string1 The first string value to be combined
 * @param {string} string2 The second string to be combined
 * @return {string} the final value of string1 and string2 after they are combined
 */
// = all this is doc & block
// In example, George broke style with adding:
const result = string1 + string2
return result
// He added: // using a redundant variable to make the code more re-usable.
// const line equivalent to `${string1}${string2}`

isLoggedInController is middleware — a function that runs before the actual controller on any route that requires the user to be authenticated. It checks whether a valid session exists. If missing or invalid, it returns a 401 Unauthorized response immediately. If valid, it calls next() and the request continues. From this point forward, every Wanderlist route that modifies data had isLoggedInController sitting in front of it.

// isLoggedInController — middleware that protects authenticated routes
import type { Request, Response, NextFunction } from 'express'

export function isLoggedInController(
  request: Request,
  response: Response,
  next: NextFunction
): void {
  if (!request.session.profile) {
    response.json({
      status: 401,
      message: 'You must be logged in to perform this action',
      data: null
    })
    return
  }
  next()  // session exists — continue to the actual controller
}

export async function loader({ request }: Route.LoaderArgs) {
  const response = await fetch(`${process.env.REST_API_URL}/wanderlist`, {
    headers: { Cookie: request.headers.get('Cookie') ?? '' }
  })
  const body = await response.json()
  return body.data
}

export default function WanderlistPage() {

  return (
    <ul>
      {wanderlist.map((item) => (
        <li key={item.wanderlistId}>{item.wanderlistTitle}</li>
      ))}
    </ul>
  )
}

// ACTION — runs when a form is submitted
export async function action({ request }: Route.ActionArgs) {
  const formData = await request.formData()
  const title = formData.get('wanderlistTitle')
  await fetch(`${process.env.REST_API_URL}/wanderlist`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json',
                Cookie: request.headers.get('Cookie') ?? '' },
    body: JSON.stringify({ wanderlistTitle: title })
  })
  return redirect('/wanderlist')
}
